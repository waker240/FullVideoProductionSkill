# User-supplied sound effects

This public package includes no sound-effect recordings. `manifest.json` is an empty template, not a downloadable audio library. Add only files you own or may use, and keep source page, creator, license and attribution with the project's reviewed asset records.

A license permitting sound in a finished video does not necessarily permit distributing the original recording as a standalone skill asset. Consult the actual source terms; for example [Pixabay's license summary](https://pixabay.com/service/license-summary/) restricts standalone distribution. No Pixabay files are redistributed by this package.
