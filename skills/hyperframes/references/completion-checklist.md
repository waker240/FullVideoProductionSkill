# Completion checklist

<!-- Public portability adaptation, 2026-09-26. -->

Adapt to the requested artifact and current delivery requirements. This is not a platform rule, fixed cover-count requirement or substitute for user approval. Mark unrequested items not applicable.

- Scope/script: required source coverage, qualified claims, authoritative wording and pronunciation fixes retained.
- Review: stable candidate/version, selection, comment, protected shot and final usage reconciled. Agent QA never creates approval.
- Picture: layout, readable typography, framing, causal motion and selected register inspected at delivery size. Concepts/candidates/finals labeled honestly.
- Timing: narration, boundaries, scene mounts, captions and any spatial/fast-passage manifests agree. Rebuild downstream after voice/speed changes.
- Sound: audition selected voice/BGM/SFX alone and in a representative mix; document silence, event timing, source/license and processing order. Report numerical validation separately from listening.
- Captions: script text, punctuation, safe margins and start/middle/end synchronization checked; requested embedded/sidecar forms delivered.
- Audit: full assembly, every adjacent seam including act boundaries, protected windows and repaired neighborhoods reviewed. Retain finding → repair → recheck evidence. Stills do not prove continuous playback.
- Master: full decode succeeds; video/audio streams, duration, dimensions and frame rate verified. Inspect encoded frames and final mix, not only a browser preview.
- Deliverables: requested master, source, narration/lossless audio, chapters, covers and publishing copy retained. Cover count, aspect and method follow the brief. Count current files/manifests.
- Rebuild: prompts, provenance, versions and commands present; selected assets are project-local; secrets and private dependencies absent.
- Handoff: clean up only within authorized scope, preserve approved originals/evidence, give actual paths and limitations, and save a short retrospective.
